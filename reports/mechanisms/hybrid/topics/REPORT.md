# Plaintext-signal test: MS 408 section vocabulary vs topic-driven hybrids and pure generators

_Auto-generated by `python -m msdecipher hybrid-topics`. **MS 408 is undeciphered; this does not identify any plaintext.** It asks whether the strength of MS 408's section-specific vocabulary is what (i) a generator with no plaintext, (ii) a hybrid fed topic-structured Latin, or (iii) a hybrid fed topic-mixed Latin would produce._

## 1. Method

Unit of analysis: the *folio* (the page-level running text of MS 408 'P', label = the folio's illustration section: herbal, recipes ('stars'),
biological, pharmaceutical, cosmological+astronomical merged; text-only pages are generated but not classified).  For MS 408 and for every
generated corpus **laid out on the same folio sequence** (same section and token count per folio) we compute, with identical code:

* **between-section JS divergence** of word distributions (mean over section pairs, bits) and its excess over a label-permutation null
  (folio labels shuffled, class sizes kept; finite-size bias cancels);
* **section-classification accuracy on held-out folios** (balanced accuracy and macro-F1; TF-IDF + logistic regression, and multinomial NB;
  5-fold stratified CV *by folio*, 3 repeats) against a label-permutation null;
* **section-keyword reproducibility**: for each section, top-30 over-represented word types (relative-frequency ratio, min count 5) in two
  random halves of its folios; overlap of the two lists (null: shuffled labels);
* **folio-block uncertainty** for MS 408: bootstrap over folios (and per-folio correctness bootstrap for accuracy).

Generated corpora (``MODELS``): topic-matched hybrids (each section's innovations come from a topical Latin work: herbal <- Pliny XX-XXVII,
pharmaceutical <- Celsus, biological <- Pliny VII-XI, recipes <- Macer, cosmo/astro <- Isidore, text-only <- Augustine -- an arbitrary but
documented assignment that *maximises* topic contrast), the same hybrids with **topic-mixed** plaintext (each folio draws its work at random: no
section <-> topic link, the null for 'topic-structured plaintext'), a **single-work** control, the no-plaintext control C0, the pure Naibbe
cipher (matched / mixed) and the authors' self-citation generator sliced into the folio layout.  Because every generator has local drift
(copying from recent words, continuous plaintext) and sections are contiguous runs of folios, 'topic-mixed' and the pure generators measure how
much section signal drift alone produces.


Folios classified: 201 (herbal 128, recipes 25, biological 19, pharmaceutical 16, cosmo-astro 13). MS 408 permutations: 1000; generated corpora: 10 seeds per model (permutation null per corpus: 100). Hybrid parameters: the all-MS-408 fits of step 1 (`hybrid_params_all_ms408.json`).

## 4. Reading

* MS 408: between-section JS 0.406 bits (null mean 0.246, z = 10.0, permutation p = 0.0010); NB balanced accuracy 0.723 (null mean 0.200, p = 0.0010; chance = 0.20); LR 0.662; keyword overlap 0.285 (null 0.152). So the section signal is real and large in this transcription.
* A1 (Naibbe tokens + copy-modify): NB balanced accuracy 0.328 with topic-matched plaintext vs 0.240 with topic-mixed (MS 408 0.723); JS excess 0.001 vs -0.003 (MS 0.160).
* A2 (codebook + copy-modify): NB balanced accuracy 1.000 with topic-matched plaintext vs 0.262 with topic-mixed (MS 408 0.723); JS excess 0.434 vs -0.016 (MS 0.160).
* B (reverse): NB balanced accuracy 0.463 with topic-matched plaintext vs 0.426 with topic-mixed (MS 408 0.723); JS excess 0.004 vs 0.004 (MS 0.160).
* pure Naibbe cipher: NB balanced accuracy 0.324 with topic-matched plaintext vs 0.213 with topic-mixed (MS 408 0.723); JS excess 0.002 vs -0.004 (MS 0.160).
* Pure generators on the same folio layout (no plaintext): C0 NB accuracy 0.204, self-citation (Java) defaults 0.554, fitted 0.542; JS excess 0.004 / 0.029 / 0.029. These measure how much section signal copying/drift alone produces (sections are contiguous runs of folios).
* **Drift-aware reading.** Against labels circularly shifted along the folio order (contiguous section runs kept) MS 408's NB accuracy 0.723 exceeds the null mean 0.406 and its maximum 0.611 over 181 shifts (p = 0.0055, the smallest attainable). The exchangeable-folio permutation is passed by almost every drifting generator, so only the comparison with generators on the same layout is informative: the best no-codebook generator reaches NB 0.554 (self-citation Java), all hybrids with Naibbe-token or edit-driven plaintext stay at 0.33-0.46, and the only generator that reaches MS 408's level is the whole-word codebook with topic-matched plaintext, which overshoots (NB 1.00, JS excess 0.43 vs MS 0.16).
* **Within a Currier language** (language/scribe is confounded with section): MS 408 NB accuracy 0.944 (A: herbal vs pharmaceutical) and 0.976 (B: herbal/biological/recipes). Generators on the same restricted layouts: self-citation 0.83 / 0.65, C0 0.49 / 0.37, topic-matched A1 0.51 / 0.53, topic-matched A2 1.00 / 1.00. The section signal does not reduce to the Currier A/B split.
* **What this does and does not show.** MS 408's folio-level vocabulary differs by section more than drift in any of these generators produces, and more than Currier language alone explains. It is therefore *consistent with* section-dependent content passing into the text (a topic-structured plaintext carried by a word-level code is one such source), but a generator whose parameters or seed page change by section would also produce it, and that alternative was not tested. A codebook with arbitrary Latin topics overshoots the observed strength, so the data neither demand nor reject a strong topic link.

## 5. Limitations

* The topic assignment of Latin works to sections is arbitrary (chosen to maximise contrast); it shows what a topic-structured source *could* pass through a generator, not what MS 408's source is.
* Sections are contiguous runs of folios and each generator drifts; 'topic-mixed' and the no-plaintext rows are the drift baselines. Currier language/scribe is confounded with section (herbal and pharmaceutical are mostly Currier A, biological and recipes mostly B), so a section signal can also arise from language/scribe differences with no topic at all — the within-language rows are the partial control.
* Classification uses folio bags of words; generated folios have the same lengths as the real ones, but the generators have no notion of scribe, line or paragraph.
* Folio-block CIs treat folios as exchangeable resampling units; bifolio/quire structure is ignored (no folio→quire map in the repo).
* The result depends on the fitted hybrid parameters (little identified) and on a simplified copy-modify engine; a null result for the hybrid does not rule out other plaintext-dependent mechanisms.
