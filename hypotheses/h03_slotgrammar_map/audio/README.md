# Audio illustrations (NOT evidence)

Renderings of the first text line of folio f1r under the learned 12-slot grammar (fitted on all of MS 408), pitch tied to slot index (143 cents per slot, 174 Hz for slot 1 up to 433 Hz for slot 12; within-slot offsets by unit frequency rank). Pitches above 1.4 kHz are folded by octaves.

* `slot_melody_rising_paths`: one note per unit, 0.16 s; every word rises, by the definition of a slot path (not a finding).
* `slot_chords_one_chord_per_word`: one 0.45 s chord per word made of the pitches of the slots the word fills (the word's 'slot-occupancy pattern').
* `NULL_slot_pitches_permuted`: same notes with the 12 slot pitches randomly permuted: the contour is no longer rising.

Hearing a rising contour proves nothing: it is guaranteed by the grammar. Whether the slot patterns carry any information is tested in `../README.md`, and the sheet's values do not fix the map.
