# Audio illustrations (NOT evidence)

Sine-tone renderings of the first text line of folio f1r (ZL 3b transcription, collapsed EVA units) under candidate unit-to-pitch maps from `results/map_table_wide_T1.csv`. Each unit is a 0.16 s note, words are separated by 0.10 s of silence, pitches above 1400 Hz are folded down by octaves. The maps are hypotheses invented for this study; the sound of a line says nothing about the manuscript unless the map beats the null tests in `../README.md` (it does not establish any meaning in any case). `NULL_random_permutation_of_c_pos` has the same pitches as `c_pos` assigned to random units: listen for the difference between contour-regular and arbitrary melodies.
