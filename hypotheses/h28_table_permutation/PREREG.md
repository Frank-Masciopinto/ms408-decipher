# h28: permutations of the real Naibbe tables (pre-registration)

Written and committed before any h28 computing. No translation claims. Do not edit this file after the pre-registration commit.

## Question
Which level of the author's tables carries the h26 match: the letter-to-string mapping, the prefix/suffix role split, or the order of glyphs inside each string?

## Cipher
- Start from `data/mechanisms/naibbe_tables.csv`. Write one permuted CSV per (condition, seed) under `tables/`. Do not modify the original file.
- Engine, copy layer, encryption seeds, copy seeds, token budget, scorer, cell kind, and worker count: same as h27 (`NH`, swap c = 0.05, seeds 1..5, Boccaccio, bifolium primary).
- Plaintext is real Boccaccio only.
- EVA segmentation for the copy layer and for the unit shuffle: `run_h19.seg_fn("eva")`.
- Workers: 1. Do not edit files outside `hypotheses/h28_table_permutation/`.

## Permutations (seed `4000 + s` for the shuffle; encryption seed stays `s`)
- **letter:** for each (state, table), permute the 23 glyph strings across the 23 letters. The multiset of strings in that slot is unchanged.
- **state:** unigram strings stay in place. For each table, pool the 23 prefix strings and 23 suffix strings, shuffle that pool, and write it back onto the prefix and suffix slots. This keeps the affix-string inventory and breaks prefix/suffix complementarity.
- **unit:** segment each glyph string into collapsed EVA units, shuffle those units, and join them back. Unit length of every code is unchanged. Internal order (including `qok-` / `-edy` patterns) is not. Strings of one unit stay as they are; report the share of strings the shuffle actually changes.

Assert before scoring that `"".join(seg(s)) == s` for every original table string. If any string fails, stop.

## Measures
Same h20 fingerprint as h27.

## Decision rule
A condition **matches** if its bifolium mean distance is ≤ 5.43 (the h26 real-table + swap anchor 3.43, plus 2) and its ≥4/5 rate is ≥ 0.60. The anchor is not recomputed.

## Predictions
- **A1.** `letter` matches. The letter-to-string mapping is not required.
- **A2.** `state` does not match. Prefix/suffix complementarity is required.
- **A3.** `unit` does not match. Within-string order is required.

Reading, after the three pass/fail calls:
- A1 pass and A3 fail: the match is orthography, not which letter owns which string.
- A2 fail and A1 and A3 pass: the match is the prefix/suffix split.
- All three pass: length and homophony are enough.
- All three fail: no single one of these three cuts is the carrier.
