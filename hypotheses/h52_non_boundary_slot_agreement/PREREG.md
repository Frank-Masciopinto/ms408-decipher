# h52: do non-adjacent word slots still agree after the boundary junction is removed? (pre-registration)

Written before any h52 computing. No translation claims. Do not edit this file after it is committed.

## Question
`h31` and `h34` showed that the last unit of a word predicts the first unit of the next word, and `h47` reproduces that link by choosing the next word from `r(first | previous last)`. A constructed language with agreement or combinatorial slot rules would still couple **non-touching** slots: the opening of word `t` with the ending of word `t+1`, or the interior of word `t` with the interior of word `t+1`, after the touching pair `(end of t, onset of t+1)` is held fixed. The page-and-line copier has no such rule. Does MS 408?

## Streams
Same token span for the manuscript and the copier: the `h47` template, `h47_lib.load_template(hand)` (up to 10,500 tokens).

- **MS:** Hands `1A`, `2B`, `3B`, words taken from that template.
- **Copier:** `page_line_copier_1A`, `page_line_copier_2B`, `page_line_copier_3B` from `hypotheses/h47_page_line_generator/results/streams.json` key `generated_lines`, zipped onto the same template. Line counts and line lengths must match.
- **Reference prose (not part of the pass rule):** `it_cucina` and `it_sidrach` from `h30_lib.load_control` (`italian/pg33954.txt`, `pg44549.txt`, 10,000 tokens).

## Slots
Units are collapsed EVA units (`h13_lib.SEG`) for MS and the copier, and characters for the prose controls.

For a word with units `u`:

- `onset = u[0]`
- `end = u[-1]`
- `core = u[1]` when `len(u) >= 3`, otherwise the label `SHORT`

Within each stream, any onset, end, or core label that occurs on fewer than 30 tokens is replaced by `OTHER`. `SHORT` is never rebinned.

## Pairs
Successive words on the **same line only**. No pair crosses a line break.

- **F1 (prefix of `t` with suffix of `t+1`):** `L = onset_t`, `R = end_{t+1}`, stratum `K = (end_t, onset_{t+1})`.
- **F2 (interiors):** `L = core_t`, `R = core_{t+1}`, stratum `K = (end_t, onset_{t+1})`.
- **F3 (suffix with suffix, reference only):** `L = end_t`, `R = end_{t+1}`, stratum `K = onset_{t+1}`.

Lag 2 on the same line (word `t` with word `t+2`, same `L`/`R` definitions, stratum `(end_t, onset_{t+2})`) is computed for F1 and F2 and reported. It does not enter the pass rule.

## Statistic
Plug-in conditional mutual information, in bits, using only strata with at least 20 pairs:

`I(L; R | K) = sum_k (n_k / n) I(L; R | K=k)`.

Null: 200 permutations (numpy seed 52). Inside every stratum, the `R` labels are shuffled. The same strata and the same 20-pair cutoff are used for the observed value and for each draw.

- `excess = observed − mean(null)`
- `z = excess / sd(null)`. If `sd(null) < 1e-12`, `z = 0`.

## Validity check
`synthetic_bind_2B`: take the copier's Hand 2B F1 rows and set every `R` equal to that row's `L`, leaving `K` unchanged. The check passes only if `excess >= 0.05` and `z >= 5`. If it fails, the pipeline is invalid and G1/G2 are not interpreted.

## Predictions
A hand-feature cell passes only when all of these hold:

- at least 500 pairs entered the conditional MI
- `excess >= 0.01` bits
- `z >= 2.58`
- `excess(MS) − excess(page_line_copier of the same hand) >= 0.01` bits

- **G1 (residual slot agreement):** some one of `{F1, F2}` at lag 1 passes on at least two of the three hands.
- **G2 (copier accounts for the residual):** G1 is false, and for every hand and for both F1 and F2 at lag 1, either `z < 2.58` or `|excess(MS) − excess(copier)| <= 0.01`.

Verdict, provided the validity check passes: `supported` if G1, `refuted` if G2, otherwise `mixed`. Prose F3 is reported and does not change the verdict.
