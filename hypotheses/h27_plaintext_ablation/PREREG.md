# h27: real Naibbe tables, plaintext removed (pre-registration)

Written and committed before any h27 computing. No translation claims. Do not edit this file after the pre-registration commit.

## Question
h26 showed that the Naibbe–Italian match needs the author's hand-designed tables. This stage keeps those tables fixed and removes the plaintext, to see whether the fingerprint still appears.

## Cipher
- Engine: `h25_lib.NH` on `data/mechanisms/naibbe_tables.csv`, 6 tables, Naibbe card weights, p_unigram 17/36, max_retries 50. Same path as the h26 real-table anchor.
- Copy: `h24_lib.copy_variant`, variant `swap`, c = 0.05, W = 20, EVA segmentation (`run_h19.seg_fn("eva")`). Copy seed = `100 * s + 17`.
- Encryption seed = `s`. Output length `2 * NTOK` (`NTOK` = 10500), then the h20 scorer keeps `NTOK` tokens.
- Source text: Boccaccio only (`it_boccaccio`). No transfer.
- Scoring: `run_h20.run_cell` with that module's `R` redirected at this folder's `results/`. Cell kind `ctrl` (the D1–D5 fingerprint does not use the Naibbe plaintext LM). Bifolium is primary; quire is also scored.
- Seeds: s = 1..5.
- Workers: 1. Do not edit files outside `hypotheses/h27_plaintext_ablation/`.

## Plaintexts
Clean with `msdecipher.mech_naibbe.clean_plaintext` before measuring letter rates. Encrypt the token lists below.

- **real:** the Boccaccio token list, unchanged.
- **shuffle:** the same tokens in a seeded random order (seed `2000 + s`). Same multiset. Word-internal spelling stays; order does not.
- **zipf:** 4000 synthetic types.
  - Each type's length is drawn from the empirical length distribution of cleaned Boccaccio tokens (length at least 1).
  - Its letters are drawn i.i.d. from the empirical unigram distribution of the cleaned Boccaccio letter stream.
  - Token frequencies follow Zipf: P(rank) ∝ 1/rank, rank 1..4000.
  - Draw as many tokens as there are Boccaccio tokens (seed `3000 + s`).
  - No Italian words, morphology, or syntax.

## Measures
The h20 statistics D1–D5, match count, and distance, against the three committed MS hand rows in `hypotheses/h20_generators_vs_italian/results/cell_MS_{1A,2B,3B}.json`. Distance and match use `h20_lib.match` / `DELTA`.

## Predictions (bifolium, 5 seeds)
Let d(real), d(shuffle), d(zipf) be the mean distances.

- **P1 (main).** Plaintext is irrelevant if d(zipf) ≤ d(real) + 2. Otherwise plaintext structure matters.
- **P2.** Syntax is irrelevant and spelling is not if d(shuffle) ≤ d(real) + 2 and d(zipf) > d(real) + 2.
- **P3 (calibration).** d(real) is within 0.5 of the h26 anchor 3.43. A miss means the engine path differs from h26, and P1–P2 are then reported but not interpreted.
